# Команды

Полный список встроенных слэш-команд (`src/cli.py`). `/help` в UI
показывает тот же список.

| Команда | Описание |
|---|---|
| `/help`, `/?` | эта справка |
| `/clear` | очистить историю ТЕКУЩЕЙ сессии (в памяти, ничего на диске) |
| `/clean [logs\|trash\|snapshots\|projects\|all]` | почистить накопившийся за всё время хлам — без аргумента только отчёт, ничего не удаляет (см. [persistence.md](persistence.md)) |
| `/settings` | настройки моделей и GPU (см. [models.md](models.md)) |
| `/memory` | что помнит нейронка о пользователе/проекте, точечное/полное удаление |
| `/usage` | статистика токенов |
| `/doctor` | проверка Ollama/модели/MCP-серверов/хранилища, сколько инстансов моделей резидентно и сколько каждый занимает |
| `/reindex [путь ...]` | вручную собрать индекс для семантического поиска по коду разом — без аргументов весь проект, с аргументами только эти файлы/папки; НЕ единственный способ индекс наполнить — каждый `read_file`/`write_file`/`edit_file` тихо обновляет его в фоне сам по себе (см. [tools-and-mcp-servers.md](tools-and-mcp-servers.md)) |
| `/update` | проверить и подтянуть обновления flowAI из git |
| `/paste` | картинка из буфера обмена → плейсхолдер `[Image-N]` |
| `/img путь.jpg` | картинка с диска → `[Image-N]` |
| `/gen промпт` | сгенерировать картинку напрямую |
| `/music промпт` | потоковая генерация музыки, повторный `/music` или Ctrl+C — стоп |
| `/music_gen промпт` | один трек напрямую, без агента |
| `/gen_model промпт [--rig] [--raw] [--lod N]` | 3D-модель (см. [generative-features.md](generative-features.md)) |
| `/anim описание` | оживить риггованную модель (Animato) |
| `/gen_texture @модель @картинка` | перегенерировать текстуру по референсу |
| `/talk текст` | озвучить текст напрямую, без модели |
| `/dnd`, `/dnd new`, `/dnd <id>`, `/dnd exit`, `/dnd help` | D&D-режим (см. [dnd-mode.md](dnd-mode.md)) |
| `/inventory`, `/status`, `/facts` | только внутри активной D&D-игры |
| `/plugin` | список установленных плагинов/скилов/хуков и что каждый даёт (см. [plugins.md](plugins.md)) |
| `!команда` | выполнить shell-команду, вывод сразу уйдёт нейронке |
| `@имя_файла` | поиск файлов в текущей директории, автокомплит по имени/пути |

Горячие клавиши: `Alt+V` — вставить картинку из буфера, `Alt+R` —
голосовой ввод (Ctrl+C — стоп записи), `Ctrl+C` во время ответа/музыки —
остановить генерацию.

## Как встроенные команды соотносятся с плагинными

Порядок разрешения в `cli.py`: сначала проверяются встроенные команды
(таблица выше, статичный список `if cmd == "/..."`), и только если
введённая команда не совпала ни с одной из них — идёт поиск среди
команд плагинов/скилов (`plugins.load_commands(os.getcwd())`).

Значит: **встроенная команда всегда выигрывает** — плагин/скил не может
переопределить `/help`, `/clear` и т.д., даже если назовёт свою команду
так же. Между собой скил текущего проекта (`.flowai/skills/`)
перекрывает глобальный плагин с тем же именем — подробности и почему
именно так в [plugins.md](plugins.md).

`/plugin` без аргументов — список установленных плагинов и что каждый
даёт (команды/MCP-серверы/хуки), включает и глобальные плагины, и
скилы/хуки текущего открытого проекта.
