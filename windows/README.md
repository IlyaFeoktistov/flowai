# FlowAI — Установка на Windows

## Системные требования

- Windows 10 (версия 1809 или новее) / Windows 11
- Не менее **8 ГБ ОЗУ** (рекомендуется 16 ГБ)
- Около **10 ГБ** свободного места на диске (полный стек: LangChain/LangGraph/MCP/FastAPI + модель + Git for Windows)
- Стабильное интернет-соединение для скачивания модели

Это **полная** версия flowAI — тот же агент с тем же набором тулов (чтение/правка
файлов, git, поиск по коду, память о проекте), что и на Linux/WSL2, не урезанный
чат. Единственное, что этот установщик сознательно не ставит — тяжёлые
опциональные части, требующие GPU/CUDA-сборки из исходников (генерация/
редактирование картинок, голос, `/gen_model`): для них см. корневой
[`README.md`](../README.md).

## Установка (один раз)

1. Получите проект одним из двух способов:
   - **Git** (если установлен): откройте PowerShell или командную строку в нужной папке и выполните
     ```
     git clone https://github.com/IlyaFeoktistov/flowai.git
     ```
     или по SSH:
     ```
     git clone git@github.com:IlyaFeoktistov/flowai.git
     ```
   - **Без Git**: скачайте архив проекта (кнопка **Code → Download ZIP** на странице репозитория) и распакуйте его в любую папку
2. Откройте папку `windows\`
3. Дважды кликните по файлу **`setup.bat`**
4. Следуйте инструкциям на экране — скрипт установит всё автоматически

Скрипт сделает следующее:
- Установит **Python 3.12** (если не установлен)
- Установит **Ollama** — программу для запуска языковых моделей
- Установит **Git for Windows** (если не установлен) — даёт агенту настоящий
  `bash`, через который работают все его shell-тулы (git, grep, любые команды в
  чате). Без него сам чат работает, но агент не сможет ничего выполнять в
  проекте — только отвечать текстом
- Поставит полный набор python-зависимостей (LangChain/LangGraph/MCP/FastAPI и т.д.)
- Скачает языковую модель **qwen2.5:7b** (~4.7 ГБ, делается один раз)
- Создаст файл настроек `.env`
- Создаст файл запуска `Запустить FlowAI.bat` в корне папки проекта

## Запуск

После установки просто открывайте `Запустить FlowAI.bat` из корня проекта.

## Языковые модели

По умолчанию устанавливается **qwen2.5:7b** (~4.7 ГБ) — хорошая модель с балансом
качества и скорости. На компьютере без видеокарты работает медленнее (30-60 сек на ответ).

Если компьютер слабый и нет видеокарты, можно поставить облегчённую версию:

1. Откройте файл `.env` в текстовом редакторе (Блокнот)
2. Измените строку: `OLLAMA_MODEL=qwen2.5:3b`
3. Скачайте модель, запустив в командной строке: `ollama pull qwen2.5:3b`

## Токен HuggingFace (только для генерации изображений)

> Генерация изображений требует мощной видеокарты NVIDIA (12+ ГБ VRAM)
> и дополнительных установок. Без этого все остальные функции работают в штатном режиме.

Токен нужен для скачивания некоторых моделей изображений с сайта HuggingFace.

**Как получить токен:**

1. Зарегистрируйтесь или войдите на [huggingface.co](https://huggingface.co)
2. Нажмите на свой аватар (правый верхний угол) → **Settings**
3. В левом меню выберите **Access Tokens**
4. Нажмите **New token**, введите любое название, выберите тип **Read**
5. Нажмите **Create token** и скопируйте токен (начинается с `hf_...`)

**Как добавить токен в приложение:**

1. Откройте файл `.env` в текстовом редакторе (Блокнот)
2. Найдите строку `HF_TOKEN=` и вставьте свой токен:
   ```
   HF_TOKEN=hf_ВашТокенЗдесь
   ```
3. Сохраните файл

## Известные ограничения нативной Windows-версии

Поддержка нативной (не WSL2) Windows — новая и **не проверялась на реальной
Windows-машине**, только по коду. Если что-то из этого списка ведёт себя не
так — это ожидаемо на первых порах, сообщите об этом.

- Shell-тулы агента (`bash`/`bash_bg`) идут через `bash.exe` из Git for Windows
  (`mcp_agent/servers/bash_windows_server.py`), а не через полноценный Linux —
  это MSYS-окружение: большинство обычных команд (git/grep/find/ls/cat/`&&`)
  работают как на Linux, но экзотика, завязанная на настоящее POSIX-ядро
  (сложные права доступа, символические ссылки определённого вида, некоторые
  системные вызовы), может вести себя иначе или не работать вовсе.
- Фоновые команды (`bash_bg`) используют отдельный watchdog-процесс
  (`powershell Start-Sleep` + `taskkill`) для аварийной остановки зависших
  job'ов вместо Linux-механизма — это Windows-специфичный код с наименьшим
  реальным пробегом среди всего перечисленного здесь.
- `expert_streaming` (быстрый бэкенд для дефолтной модели `glm-4.7-flash`) —
  не собирается на Windows этим установщиком, отсюда переключение на
  `qwen2.5:7b` в `.env` (см. «Языковые модели» выше и корневой README про
  `expert_streaming`).
- Генерация/редактирование картинок, голос, `/gen_model` — не устанавливаются
  этим скриптом вообще (нужны отдельные GPU/CUDA-сборки, см. корневой
  `README.md`).

## Решение проблем

**«winget не найден»**
Обновите Windows через Центр обновления или установите
[App Installer](https://apps.microsoft.com/detail/9NBLGGH4NNS1) из Microsoft Store.

**Установка зависает / прерывается**
Закройте скрипт, подождите минуту и запустите снова — скрипт продолжит с того места где остановился (модель не скачивается повторно).

**«Не удалось установить Ollama через winget»**
Скачайте установщик вручную с сайта **ollama.com**, установите, затем
запустите `setup.bat` снова.

**Агент не может выполнить ни одну команду / пишет про отсутствующий bash**
Не установился Git for Windows (нужен для shell-тулов агента — см.
«Известные ограничения» выше). Поставьте вручную:
[git-scm.com/download/win](https://git-scm.com/download/win) (можно с
настройками по умолчанию), затем откройте `.env` и добавьте строку
`FLOWAI_WINDOWS_BASH=C:\Program Files\Git\bin\bash.exe` (или тот путь, куда
реально установился Git), сохраните и перезапустите flowai.

**Приложение отвечает медленно**
Это нормально при работе без видеокарты. Ответ на сложный вопрос может занимать
30-60 секунд. С видеокартой NVIDIA скорость значительно выше.
